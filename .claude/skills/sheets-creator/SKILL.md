# sheets-creator: 악보 → 자막용 가사 txt

예배 자막 담당자는 매주 악보를 보고 가사를 손으로 옮겨 적는다. 이 스킬은 그 일을 대신한다. 결과 txt는 자막·PPT 프로그램에 **그대로 붙여 넣는 것**이 목적이라, 형식이 조금만 어긋나도 화면이 깨진다. 아래 규칙은 모두 그 이유에서 나온다.

## 작업 순서

### 1. 악보 읽기

- **이미지(jpg, png)**: Read 도구로 바로 본다.
- **heic**: Read로 안 열리면 `pip install pillow-heif` 후 png로 변환해서 본다. 변환본은 작업용 임시 폴더에 두고, 사용자의 악보 폴더를 어지럽히지 않는다.
- **PDF**: 페이지를 이미지로 바꿔서 본다. 텍스트 추출은 쓰지 않는다. 악보의 가사는 음표 아래 음절 단위로 흩어져 있어서 텍스트로 뽑으면 순서가 뒤섞이기 때문이다.
  ```bash
  python <이 스킬 폴더>/scripts/pdf_to_images.py "<악보.pdf>" "<임시 폴더>"
  ```
  스크립트는 `pdftoppm`(poppler)이나 `pypdfium2` 중 있는 것을 쓴다. 둘 다 없으면 `pip install pypdfium2`를 안내한다.
- 글자가 작아 헷갈리면 해당 부분을 확대(더 높은 배율로 다시 렌더링)해서 확인한다.

한 PDF에 여러 곡이 있을 수도 있고, 곡마다 파일이 따로일 수도 있다. 곡 경계는 제목과 새로 시작하는 송폼 줄로 구분한다.

### 2. 곡 순서 정하기

사용자가 순서를 말하면 그대로 따른다("2번 곡, 1번 곡, 3번 곡"). 말하지 않으면 파일/페이지 순서를 쓴다.

### 3. 송폼 찾기

악보 위쪽에 보통 `Intro(4)-V1-V2-P.C.-C-C-B-C` 같은 송폼 줄이 있다. 이것이 **부르는 순서**다.

- 송폼 줄을 따라 가사를 펼친다. 후렴(C)이 세 번 나오면 세 번 다 적는다. `B ×2`는 B를 두 번 적는다.
- **가사가 없는 파트**(Intro, Inter, Outro 등 연주 구간)는 건너뛴다. 따로 알릴 필요 없다.
- **화이트로 지운 칸**(송폼이나 악보에서 지워진 부분)은 제외하고, 무엇을 뺐는지 마지막에 알려 준다. 인도자가 일부러 지운 것이니 따르되, 확인할 수 있게 한다.
- **송폼 줄이 없으면** 도돌이표, D.S., D.C., Coda, 1·2번 괄호(volta)로 순서를 추정한다. 추정했다는 사실과 추정한 순서를 마지막에 알려 준다.

### 4. 가사 읽기

마디별로 음표 아래 음절을 이어 붙여 읽는다(`주 나 의 모 습 보 네` → `주 나의 모습 보네`). 띄어쓰기는 한국어 맞춤법에 맞게 복원한다.

- 한 파트에 가사 줄이 여러 개(1절/2절)면 송폼의 V1, V2에 맞는 줄을 쓴다.
- 읽기 애매한 글자는 추측한 글자 뒤에 `[?]`를 붙인다(`보[?]네`). 사용자는 `[?]`만 찾아 확인하면 되므로, 확신이 없을 때는 아끼지 말고 붙인다. 틀린 가사가 예배 화면에 뜨는 것보다 낫다.

### 5. 묶음 나누기

**빈 줄로 나뉜 묶음 하나 = 자막 화면 한 장.**

- 묶음은 **항상 2줄**이다. 자막 프로그램이 묶음 단위로 화면을 넘기기 때문에 줄 수가 일정해야 한다.
- 보통 4마디가 한 묶음이다. 가사가 짧은 구간은 8마디를 한 묶음으로 합치기도 한다. 한 화면에 너무 적거나 많지 않게 읽기 좋은 양을 고른다.
- 마디 경계를 기준으로 나누되, **뜻이 끊기는 곳**에서 줄을 바꾼다. 단어 중간은 절대 자르지 않는다.
- 가사가 한 줄뿐인 묶음은 둘째 줄을 `-`로 채운다.

### 6. txt에 넣지 않는 것

다음은 화면에 뜨면 안 되므로 모두 뺀다.

- `[V1]` 같은 파트 라벨
- 송폼 줄
- 코드(`G`, `Am7` 등)
- 반복 기호(`×2`, `:||` 등)
- 손글씨 메모

### 7. 파일 쓰기

곡마다 **제목 묶음**(`제목` / `-`)으로 시작한다. 곡 사이 구분도 이 제목 묶음이 한다.

```
주 은혜임을
-

주 나의 모습 보네
상한 나의 맘 보시네

주 나의 눈물 아네
홀로 울던 맘 아시네
```

- 묶음 사이는 빈 줄 **하나**. 파일 끝에 남는 빈 줄은 없앤다.
- 인코딩은 UTF-8.
- 저장 위치: 악보와 같은 폴더.
- 파일 이름: `<첫 곡 제목> 외 N곡.txt` (N = 나머지 곡 수). 한 곡이면 `<제목>.txt`.
  파일 이름에 쓸 수 없는 문자(`\ / : * ? " < > |`)는 빼거나 바꾼다.

### 8. 마무리 보고

짧게 알려 준다.

- 저장한 파일 경로와 곡 순서
- `[?]` 표시가 몇 군데인지 (어느 곡인지)
- 지워진 칸이라서 뺀 부분
- 송폼을 추정한 곡이 있으면 추정한 순서
