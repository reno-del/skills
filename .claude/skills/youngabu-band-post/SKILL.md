# 영아부 밴드 예배 스케치 글

매주 영아부 교사 한 명이 주일 예배 사진을 밴드에 올리고 글을 쓴다. 읽는 사람은 **영아부 부모님과 선생님들**이다. 부모님은 내 아이가 예배 시간에 무엇을 했는지 궁금해하고, 선생님들은 그 주 예배를 함께 돌아본다. 그래서 글은 사진을 따라가며 예배 순서대로 "무엇을 했고 아이들이 어땠는지"를 다정하게 들려준다.

글은 밴드 편집기에 **그대로 붙여 넣고 사이사이에 사진을 끼워 넣는** 용도다. 사진이 들어갈 자리를 정확히 표시해 줘야 작성자가 헤매지 않는다.

## 작업 순서

### 1. 사진 읽기

사진이 채팅 첨부 한도(16장 안팎)보다 많으면, 사용자에게 "영아부 사진 보내기" 페이지(https://claude.ai/artifact/1aH5NNXnz1ZEwE4NCDiomf)로 보내 달라고 안내한다. 이 페이지는 사진을 줄여 PDF 몇 개와 목록(JSON)으로 올린다. Artifact 도구로 `scope: "assets"` 목록을 보고, 새로 올라온 것을 `path`에 asset id를 하나씩 넣어 받는다. 그다음 `pdfimages -j`로 사진을 꺼낸다. 순서는 PDF가 올라간 순서와 PDF 안의 쪽 순서를 따른다.

사진이 많으면(보통 100~200장) 먼저 파일 이름을 `001.jpg`, `002.jpg`처럼 받은 순서대로 번호를 붙여 작업 폴더에 복사한다. 그다음 25장씩 번호가 찍힌 모음 이미지를 만들어 한눈에 훑는다. 한 장씩 열면 시간이 너무 오래 걸린다. 슬라이드 글자처럼 자세히 봐야 할 사진만 원본을 따로 연다.

```bash
python <이 스킬 폴더>/scripts/contact_sheet.py <번호 붙인 사진 폴더> <모음 이미지 폴더>
```

받은 사진을 모두 보고, 각 사진이 예배의 어느 순서인지 분류한다. 분류 단서:

| 순서 | 사진에서 보이는 것 |
|---|---|
| 즐겁게 찬양해요 | 화면에 가사 슬라이드, 앞에서 율동하는 선생님(앞치마), 따라 하는 아이들 |
| 대표기도 | "대표기도 ○○○ 선생님" 슬라이드, 마이크 들고 기도하는 선생님 |
| 말씀을 들어요 | "○과" 공과 제목 슬라이드, 성경 구절(암송 말씀) 슬라이드 |
| 감사한 마음 | 망토(파란색·빨간색, 십자가)를 두른 아이가 헌금 주머니를 들고 있음 |
| 오감활동 | 활동 안내 슬라이드나 견본 사진, 아이들이 만들기·놀이 하는 모습 |
| 예배 스케치 | 활동 중이거나 자유롭게 노는 아이들 사진 묶음 |
| 특별 순서 | 절기 포토존, 생일 파티, 암송 대회, 행사 안내 포스터 등 |

슬라이드에 적힌 글자(공과 과 번호와 제목, 성경 구절과 출처, 대표기도 선생님 이름, 찬양 가사, 활동 이름)는 **그대로 옮겨 적는다.** 이 정보가 글의 뼈대가 된다. 글자가 흐려 확실하지 않으면 추측해서 채우지 말고 `○○○`로 비워 둔 뒤 마지막에 확인을 부탁한다. 성경 구절이나 선생님 이름이 틀리면 부모님들이 바로 알아채고, 바로잡기도 번거롭기 때문이다.

### 2. 비슷한 사진 골라내기

선생님들은 한 장면을 여러 번 연속으로 찍기 때문에, 받은 사진에는 거의 같은 사진이 여러 장 섞여 있다. 같은 장면이 줄줄이 올라가면 글이 길어지고 다른 아이들 사진이 묻힌다. 그래서 **비슷한 사진은 묶어서 그중 가장 좋은 한 장만 고른다.**

사진이 10장이 넘으면 먼저 스크립트로 비슷한 사진 묶음을 찾는다. 연속 촬영은 눈으로만 비교하면 놓치기 쉽다.

```bash
python <이 스킬 폴더>/scripts/find_similar.py <사진 폴더 또는 파일들>
```

스크립트는 구도가 비슷하거나 순서상 바로 붙어 있는 사진을 묶어 줄 뿐이다. 묶음 안에서 어느 사진이 좋은지는 직접 보고 고른다. 같은 아이를 각도만 바꿔 여러 장 찍은 사진은 스크립트가 자주 놓친다. 모음 이미지에서 같은 아이, 같은 장면이 이어지면 같은 묶음으로 친다.

`find_similar.py`도 파일 이름 순서를 촬영 순서로 본다. 그래서 1단계에서 받은 순서대로 번호를 붙여 두어야 잘 잡는다.

좋은 사진을 고르는 기준(앞에 있을수록 중요):

1. **흔들리거나 초점이 나가지 않은 사진**
2. **아이 얼굴이 보이는 사진**: 눈을 뜨고 있고, 뒤통수나 손에 가려지지 않은 것
3. **표정이 좋은 사진**: 웃거나 활동에 집중하는 모습. 우는 얼굴, 눈 감은 순간, 입에 손을 넣은 모습은 피한다. 부모님이 보고 기분 좋을 사진이어야 한다.
4. **무엇을 하는지 보이는 사진**: 오감활동이면 만든 작품이나 손동작이 함께 보이는 것
5. **잘린 데가 적고 밝은 사진**

고른 뒤에도 사진이 많으면 레퍼런스 글처럼 40~60장 안쪽으로 맞춘다. 같은 장면의 비슷한 사진부터 줄인다.

같은 아이가 여러 묶음에 나오면 괜찮지만, 한 아이 사진만 유독 많아지지 않게 고르게 섞는다. 모든 부모가 내 아이 사진을 찾아보기 때문이다.

뺀 사진은 지우지 말고 결과 끝에 "비슷해서 뺀 사진" 목록으로 알려 준다. 어떤 사진을 남겼는지와 이유를 짧게 적는다. (예: `5, 6, 7번 → 6번 사용 (5번 흔들림, 7번 눈 감음)`) 작성자가 다른 사진을 더 좋아할 수도 있기 때문이다.

### 3. 사진에 없는 정보 챙기기

다음은 사진만으로 알 수 없으니 사용자 메시지에서 찾는다. 없으면 `○○○`로 두고 글 아래에 "채워 주세요" 목록으로 알려 준다. 정보가 몇 개 빠졌다고 질문부터 하지 말고, 일단 완성 글을 먼저 보여 준다. 매주 바쁜 와중에 쓰는 글이라 바로 쓸 수 있는 초안이 더 반갑다.

- **날짜**: 사용자가 말하지 않았으면 사진 정보나 대화에서 추정하고, 모르면 `[2026.○○.○○]`로 둔다.
- **헌금위원 아이 이름 두 명**
- **찬양 곡 제목**: 가사 슬라이드가 읽히면 첫 소절을 쓴다.

**아이 이름은 사용자가 알려 준 것만 쓴다.** 사진 속 아이 얼굴을 보고 이름을 짐작하거나 지어내지 않는다. 남의 아이 이름이 잘못 붙으면 부모님 입장에서 매우 불편하다. 헌금위원처럼 원래 이름이 들어가는 자리 외에는 "우리 친구들", "영아부 아가들"처럼 부른다.

### 4. 글 쓰기

아래 구성을 따른다. 사진이 없는 섹션은 빼고, 특별 순서가 있으면 오감활동이나 예배 스케치 뒤, 마무리 앞에 넣는다.

```
[YYYY.MM.DD] 영아부 주일 예배 🫶

(여는 글 2~3줄)

🎶 즐겁게 찬양해요
📷 [사진: 찬양 1장]
☀️ (찬양 가사 한 소절) ☀️
(찬양 모습 한두 줄)

🙏 대표기도
📷 [사진: 대표기도 1장]
○○○ 선생님의 따뜻한 기도로 예배를 시작했습니다 🥰

📖 말씀을 들어요
📷 [사진: 공과 제목 슬라이드, 암송 말씀 슬라이드]
"하나님 아버지, (오늘 말씀 내용) 감사해요. (오늘 말씀대로 살게 해 달라는 간구). 예수님의 이름으로 기도합니다. 아멘."

💗 감사한 마음
📷 [사진: 헌금 2~4장]
오늘 헌금위원은 🙇‍♂️○○○ ~ ○○○🙇‍♀️
우리 친구들이 감사한 마음을 담아 하나님께 헌금을 드렸어요.💖

🏠 오감활동
(의성어·의태어~ 활동 이름 + 이모지)
📷 [사진: 활동 안내/견본 1장]
(활동이 오늘 말씀과 어떻게 이어지는지 한두 줄)
📷 [사진: 활동하는 아이들 여러 장]

🎨 예배 스케치
📷 [사진: 나머지 사진 모두]

(마무리 2~3줄)
```

위 틀의 `📷 [사진: …]` 줄은 사진이 들어갈 자리를 설명하려고 적은 것이다. **최종 글에는 넣지 않는다.** 작성자는 글을 통째로 복사해 밴드에 붙여 넣고, 사진은 밴드 편집기에서 각 섹션 아래에 따로 넣는다. 글 안에 자리 표시가 남아 있으면 하나하나 지워야 해서 번거롭다. 대신 섹션마다 어느 사진을 넣을지는 글과 분리된 "사진 넣는 곳" 목록으로 알려 준다.

#### 섹션별 쓰는 법

- **제목**: `[2026.10.11] 영아부 주일 예배 🫶` 형식. 날짜는 점으로 구분하고 월·일은 두 자리.
- **여는 글**: 계절이나 그 달 몇째 주인지로 시작해 "오늘도 우리 영아부 아가들과 가정이 함께 은혜 가득한 예배를 드렸습니다" 같은 감사로 잇고, 끝에 🤍. 예: "🍂 오늘은 가을의 따뜻함이 시작되는 첫 주일입니다 🍂", "어느덧 8월의 마지막 주일이에요".
- **찬양**: 가사 한 소절을 ☀️, 🙌 같은 이모지로 감싸 인용하고 "즐겁게 찬양 드렸어요!", "친구들과 함께 즐겁게 찬양하고 율동했어요 🎵" 처럼 잇는다.
- **대표기도**: 한 줄로 충분하다. 선생님 이름은 슬라이드에서 읽는다. "○○○ 부장 선생님"처럼 직분이 보이면 붙인다.
- **말씀**: 사진 아래 **따옴표로 감싼 짧은 기도문** 한 단락을 쓴다. 공과 제목과 암송 구절을 바탕으로 "하나님 아버지, ~해 주셔서 감사해요. ~하도록 도와주세요. 예수님의 이름으로 기도합니다. 아멘." 구조로, 영아가 따라 할 수 있을 만큼 쉽고 짧게(2~3문장) 쓴다. 공과 내용을 길게 설명하지 않는다.
- **헌금**: 위 두 줄 형식을 거의 그대로 쓴다. 매주 같은 형식이라 부모님들이 익숙해하는 부분이다.
- **오감활동**: "퐁당퐁당~", "모여모여~", "흔들흔들~", "둘러 둘러~"처럼 소리나 움직임을 흉내 내는 말로 활동 이름을 시작한다. 그다음 "~하며, (오늘 말씀)을 기억하고 감사합니다" 식으로 활동과 말씀을 연결한다. 이 연결이 이 섹션의 핵심이다.
- **예배 스케치**: 보통 사진만 넣고 글은 없거나 한 줄이다.
- **마무리**: "오늘도 예배를 통해 하나님을 만나고 친구들과 함께 소중한 시간을 보냈습니다." 처럼 하루를 정리하고, "이번 한 주도 하나님의 사랑 안에서 건강하고 행복하게 지내길 바라며 다음 주일에도 즐거운 마음으로 다시 만나요!" 처럼 한 주 축복과 다음 주 인사로 끝낸다. 끝에 💗 또는 🤍. 계절에 맞는 기도 부탁을 넣어도 좋다.

#### 말투

- 기본은 "~습니다"와 "~어요"를 섞는다. 여는 글·마무리는 "~습니다/~했습니다", 사진 설명은 "~했어요/~드렸어요"가 자연스럽다.
- 아이들은 "우리 영아부 친구들", "아가들", "우리 친구들"로 부른다.
- 이모지는 문장 끝이나 섹션 제목에 하나씩. 한 문장에 여러 개를 몰아 넣지 않는다. 자주 쓰는 것: 🤍 💗 💖 🩷 🙌 🥰 😊 🎵 ✨ 🍂 ☀️
- 사진에 보이는 구체적인 모습을 한 줄씩 짚어 주면 좋다 ("토끼 가면을 쓰고 말씀 당근을 먹는 친구들"). 다만 특정 아이를 지목해 평가하는 말("○○이만 울었어요")은 쓰지 않는다. 모든 부모가 보는 글이기 때문이다.

### 5. 결과 보여 주기

작성자는 결과를 **복사해서 바로 밴드에 올린다.** 그래서 코드 블록 안에는 밴드에 올라갈 글만 넣는다.

1. **완성 글**: 하나의 코드 블록으로 보여 준다. `📷` 자리 표시, `○○○`, 괄호 메모 같은 작업용 표시는 하나도 남기지 않는다.
   - 정보가 없어 확실히 쓸 수 없는 문장은 비워 두지 말고 빼거나, 사진에서 확인되는 사실만으로 쓴다.
   - 무슨 순서인지 모르는 사진 묶음은 억지로 섹션을 만들지 말고 예배 스케치에 넣는다.
   - 헌금위원 이름처럼 꼭 필요한데 정말 모르는 정보만 예외로 `○○○`를 남긴다. 이때는 코드 블록 바로 위에 "○○○만 바꿔서 올리세요"라고 알린다.
2. **사진 넣는 곳**: 코드 블록 아래에 섹션 이름별로 넣을 사진 번호를 한 줄씩 적는다.
3. **밴드 올리기용 zip**: 고른 사진을 글에 나오는 섹션 순서대로 폴더에 나눠 담아 zip으로 준다. 작성자는 밴드에 글을 붙여 넣은 뒤, 섹션 제목 아래에서 사진 추가를 누르고 해당 폴더 사진을 전체 선택하기만 하면 된다. 글에 넣은 섹션 순서 그대로 `섹션.json`을 만들어 실행하고, 만든 zip은 SendUserFile로 보낸다.
   ```bash
   python <이 스킬 폴더>/scripts/package_for_band.py <번호 붙인 사진 폴더> <섹션.json> <출력.zip>
   ```
   zip을 보낼 때 **아이폰·아이패드** 사용자에게는 아래 순서를 함께 알려 준다. 밴드 앱의 사진 추가 화면은 '사진' 앱 보관함만 보여 주므로, 파일 앱에 압축을 푼 것만으로는 사진이 보이지 않는다. 그래서 스크립트가 JPEG마다 EXIF 촬영 시각을 올릴 순서대로 넣어 둔다. '사진' 앱에 저장해도 순서가 그대로 유지된다.
   1. 파일 앱에서 zip을 눌러 압축을 푼다.
   2. 섹션 폴더를 열고 오른쪽 위 '선택' → '모두 선택' → 공유 버튼 → '이미지 n개 저장'을 누른다. 모든 폴더에 이렇게 한다. 저장하는 폴더 순서는 상관없다(촬영 시각으로 줄을 세우므로).
   3. 밴드 앱에서 사진 추가를 누르면 '최근 항목' 맨 아래에 올릴 순서대로 모여 있다.
   **영상**은 크기가 커서 받지 않는 것이 보통이다. 사용자가 어떤 영상이 있는지 말해 주면, 영상이 들어갈 섹션을 정하고 영상에 맞는 문장을 글에 넣는다. 그리고 "사진 넣는 곳" 목록에 "찬양: 영상 1개(율동) 먼저, 그다음 사진"처럼 적어 준다. 영상 파일은 작성자가 휴대폰에서 바로 넣는다.
4. **비슷해서 뺀 사진**: 뺀 사진이 있으면 목록을 짧게 붙인다(2단계 참고).
5. **확인할 점**: 빼거나 바꾼 내용이 있으면 한두 줄로 알린다. 예: "선물 사진은 무슨 선물인지 몰라서 스케치에 넣었어요."

## 참고 예시

실제 밴드 글을 옮겨 적은 예시가 `references/examples.md`에 있다. 말투나 길이가 헷갈리면 읽어 본다. 예시의 문장을 그대로 베끼기보다, 그 주 사진과 말씀에 맞게 새로 쓴다. 매주 같은 문장이 반복되면 부모님들이 읽지 않고 넘기게 된다. 단, 헌금 두 줄처럼 매주 고정된 형식은 그대로 쓴다.
