# 영아부 찬양 가사

영아부에서 부르는 찬양의 가사를 곡마다 txt 하나로 둔다. 파일 이름은 곡 제목이다(`하나님 저 왔어요.txt`).
음원(mp3, m4a)을 받으면 `scripts/song_info.py`로 가사를 뽑아 여기에 저장한다. 음원 파일은 넣지 않는다.

```
# 곡 제목
출처: mp3 태그 가사 | 음성 인식(확인 전) | 사용자 확인
원본: 파일이름.mp3
주제: 가사가 무엇을 노래하는지 한 줄 (찬양 섹션 문장을 새로 쓸 때 실마리로 쓴다)
확인할 곳: 음성 인식 글자를 짐작해 고친 곳 (없으면 이 줄은 뺀다)

(가사, 한 줄에 한 소절. 같은 부분을 되풀이하는 곳은 한 번만 적고, 절이 바뀌면 빈 줄)
```
